# Zepto Clone – Backend

A grocery delivery backend project built using Python, Flask, MySQL, and SQLAlchemy.

## Technologies
- Python
- Flask
- MySQL
- SQLAlchemy
- JWT Authentication

## Features
- Customer Management
- Product Management
- Inventory Management
- Order Management
- Rider Management
- Delivery Management
- User Authentication

## Project Structure
```text
zepto_clone/
├── models/
├── app.py
├── extensions.py
├── test_env.py
└── .gitignore
```

## Setup

1. Clone the repository:
```bash
git clone https://github.com/gurupankaj235-design/zepto_clone.git
```

2. Install dependencies:
```bash
pip install Flask Flask-SQLAlchemy PyMySQL python-dotenv Flask-JWT-Extended Flask-Cors
```

3. Configure your `.env` file.

4. Run the application:
```bash
python app.py
```
